# Exp204 — Causal edge predictor (negative)

2026-11-21. Tested 6 configurations on eight bundled scikit-image examples resized to 96×96 RGB, with first four for development and last four held out. Predictors: left, up, causal edge decision (left vs up by distance to upper-left), and JPEG-LS-like nearest-of-left/up/upper-left; reversible green decorrelation; zlib9 and LZMA6. All 48 encoded streams round-tripped exactly and truncated streams were rejected. Selected solely on development: paeth / green transform / zlib9. Held-out complete encoded sizes: BLKH prototype 30,411 bytes; Pillow WebP lossless quality=100 method=6 20,354 bytes; BLKH +49.41% (worse). CPU scalar Python timings and per-image SHA256 in local experiment bundle. Environment: Linux 6.18.57 x86_64, Pillow 12.3.0.

This is NOT a competitive discovery. Important limitations: only bundled scikit-image examples (no independent external photographic corpus), no AVIF/JPEG XL, no rate-distortion curves, no isolated RSS, and no GitHub Actions run. The executable and raw JSON are in the local Exp204 bundle and are NOT committed here.
