# Exp264 — reversible delta / XOR with Brotli (2026-11-23)

New independent local execution, after reviewing Exp263 and prior experiments. Eight scikit-image images converted to RGB 96x96; predetermined development split astronaut/coffee/chelsea/rocket, held-out test camera/coins/moon/page. Six reversible transforms (raw, row/column delta, channel delta, row/column XOR) times zlib level 9, LZMA preset 6, Brotli quality 9 = 18 candidates, 144 BLKH encode/decode round trips, plus 16 PNG/WebP lossless controls. All 160 decoded pixel arrays matched source exactly. Real B264 14-byte binary header and full payload counted.

Selected solely on development: column_delta + LZMA. Dev: 60,444 bytes. Held-out test: BLKH 23,200 bytes, WebP lossless 19,452 bytes, PNG 38,225 bytes. BLKH **19.27% larger than WebP** (negative result). Pillow 12.3.0/libwebp 1.6.0, Python 3.13.5, NumPy 2.3.5, Linux 6.18.57. Local reproducible source and individual records: /mnt/data/blkh_exp264/bench.py and results.json (not yet committed). No independent external photographic dataset, AVIF/JXL, lossy rate-distortion, isolated RAM, or GitHub Actions reproduction. The scikit-image source overlaps earlier studies, so these are held-out *within-run* images, not an independent external corpus. No competitive discovery. No demo or LinkedIn recommendation.
