# Exp210: local tile palettes versus WebP lossless

Experiment executed locally on Python 3.13.5, Pillow 12.3.0. 8 configurations: tiles 16,32,64,128 with zlib9 or LZMA6; 8 images (4 development, 4 held-out test), 64 complete encode/decode validations. Each candidate stream includes header, tile lengths, palette and payload. RGB exact roundtrip and truncated-stream rejection tested. Selection on development: tile 128/LZMA6. Held-out aggregate: 72,112 bytes versus 47,916 bytes WebP lossless (50.50% larger). Two held-out images are synthetic palette images, not independent photographs. Negative result; no superiority claim. Local executable and JSON results generated separately, not yet uploaded to this branch. No Actions run. Pending: external photographic datasets, AVIF/JXL, memory-isolated benchmark, reproducible CI. Do not publish demo/LinkedIn based on this result.
