# Exp110 — RGB residual byte layout ablation (2026-11-17)

**Hypothesis:** reordering Paeth residual bytes from RGB interleaved into channel-planar or bit-plane-packed order could improve generic entropy coding. Three reversible layouts (interleaved, planar, bit-plane) were evaluated with zlib-9 and LZMA-6, with 14-byte header included. The decoder uses no original image.

## Local exploratory results
Executed Python unittest: 3 methods passed (layout inversions, 15 encode/decode roundtrips, malformed/trailing data rejection). Seven scikit-image RGB8 examples were thumbnail-resized to <=96x96, all decoded byte-exact. Pillow PNG (compress_level 9) and WebP lossless (method 6, quality 100) also decoded exactly. Single-run encode/decode times and six-way ablation results are generated by bench.py. Process peak RSS: 146772 KiB on local Linux, including libraries and image loading.

| Image | Exp110 bytes | PNG bytes | WebP lossless bytes | selected layout |
|---|---:|---:|---:|---|
| astronaut | 15874 | 18886 | 14210 | interleaved |
| chelsea | 9886 | 12367 | 9094 | planar |
| coffee | 11430 | 12716 | 9742 | planar |
| rocket | 7666 | 8360 | 6988 | interleaved |
| hubble_deep_field | 12518 | 15308 | 10702 | planar |
| immunohistochemistry | 18058 | 20859 | 17046 | planar |
| colorwheel | 7142 | 7862 | 4578 | interleaved |

LZMA won all seven. Bit-plane packing lost against both other layouts in all seven. Planar ordering reduced size on 4/7 images; nevertheless **WebP lossless won 7/7**. These are repeated exploratory same-library examples, not independent holdout evidence. This is a **negative competitive result**, not a breakthrough.

Reproduce: `python -m pip install pillow scikit-image numpy`, then `cd research/exp110 && python -m unittest -v test_exp110.py && python bench.py > results.json`.

Limitations: no AVIF/JPEG XL, no independent external corpus, no statistically robust timings, no matched-distortion lossy rate-distortion curves; peak RSS includes Python, libraries and image loading. A CI run must be verified before claiming independent reproduction. Follow-up should prioritize an independently sourced dataset and JPEG XL lossless before additional tuning on these same images. Do not prepare a superiority demo or LinkedIn announcement.
