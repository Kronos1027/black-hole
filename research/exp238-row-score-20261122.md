# Exp238 — row-wise signed-residual score (2026-11-22)

## Hypothesis
Choose independently for each RGB channel and row among zero, left, up and MED prediction, minimizing the sum of signed-magnitude residuals. Compare with fixed up and MED. The selection bytes are serialized and included in the compressed payload.

## Actual local execution
Script: /mnt/data/exp238/bench.py; results: /mnt/data/exp238/results.json (local artifacts, **not yet committed**). Python 3, NumPy 2.3.5, Pillow 12.3.0, scikit-image 0.26.0. Six skimage images, converted to RGB and resized to 96x96, first three development, last three held out. 36 experimental round trips plus 12 PNG/WebP controls, all RGB exact.

| Variant | Dev bytes | Held-out bytes |
|---|---:|---:|
| up + zlib9 | 61033 | 55616 |
| up + LZMA6 | 56510 | 51858 |
| MED + zlib9 | 59684 | 55455 |
| MED + LZMA6 | 56686 | 52706 |
| adaptive + zlib9 | 59646 | 55059 |
| adaptive + LZMA6 | **56478** | 52214 |
| PNG | 57053 | 52457 |
| WebP lossless | **42724** | **40872** |

Dev-selected adaptive+LZMA6 is 27.75% larger than held-out WebP lossless (52214/40872 - 1). Fixed up+LZMA6, although not selected on development, is slightly better on held-out at 51858 bytes. This is not evidence of generalization or codec superiority.

## Method and limitations
Actual BL38 bytes include a 14-byte header, full selector bytes and entropy payload. Decoder reconstructs RGB exactly from the serialized stream, not from source arrays. Times are recorded per case in local JSON. This small skimage corpus is not an independent external benchmark. No AVIF/JPEG XL executable, no isolated RSS measurement, no R-D curve, and no Actions reproducibility. Local script and JSON still need upload to this branch before CI can run. Do not claim breakthrough, publish demo or LinkedIn.
