# Exp239: second-order horizontal residuals and planar layout (2026-11-22)

Executed locally with Python, NumPy, Pillow, scikit-image, zlib and LZMA. Tested six 96x96 RGB images from scikit-image (dev: astronaut, coffee, chelsea; held-out: rocket, immunohistochemistry, hubble_deep_field). Six reversible layouts/predictors (raw, planar, first-order horizontal, second-order horizontal, vertical, green-relative horizontal) crossed with zlib level 9 and LZMA preset 6. **72 successful exact RGB encode/decode roundtrips** and 12 PNG/WebP lossless baseline roundtrips. Initial inverse second-order implementation failed assertion; fixed the order of reconstructing x=1 before x>=2, then reran all tests successfully.

Dev-selected vertical delta + LZMA: **53,502 bytes on dev**, **49,342 bytes on held-out**; WebP lossless held-out **40,458 bytes**; PNG lossless held-out **52,457 bytes**. BLKH candidate **21.96% larger than WebP**, though 5.94% smaller than PNG. All candidate sizes include a serialized 14-byte header. Selection performed only on dev. No competitive breakthrough.

Limitations: sample of six internally bundled photographs, resized to 96x96; not an external independent corpus; lossless-only (no rate-distortion curve); AVIF/JPEG XL executables absent; process-wide peak RSS is not isolated per codec; no Actions reproduction yet. Local runnable artifacts generated at /mnt/data/exp239/bench.py and results.json, **not yet checked into repository**. Next step: incorporate runnable benchmark and fixture manifest into GitHub Actions, test external licensed corpora, compare AVIF/JXL, collect per-process RSS.
