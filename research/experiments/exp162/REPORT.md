# Exp162 — row entropy / compressed-size selectors (2026-11-19)

Local executable experiment in /mnt/data/exp162/experiment.py; **script and JSON are NOT yet committed**. Tested 8 scikit-image images resized to RGB 128x128, development: astronaut, coffee, chelsea, rocket; held-out: camera, coins, moon, horse. 4 row selection strategies (fixed up, entropy, signed-residual SAD, zlib row size) x zlib-9/LZMA-6 = 64 exact BLKH encode/decode roundtrips. WebP lossless via Pillow method=6, each file decoded pixel-identically. BLKH serialized files include header, row selectors when adaptive, payload and CRC32. All 64 passed exact RGB reconstruction. Selected **fixed_up + LZMA-6** only from development, 103040 B vs WebP 82660 B. Held-out: **29836 B BLKH vs 24362 B WebP**, 22.47% larger. Neither entropy nor compressed-size selectors won. Peak whole-process RSS 158732 KiB; individual codec RAM not isolated. Timings are single-run and not stable benchmarks.

Limitations: built-in images are not independent external photographs; AVIF/JXL unavailable; no lossy rate-distortion curve; no Actions reproducibility. No competitive discovery, no demo or LinkedIn publication. Next: commit runnable script and JSON, add CI, independent dataset manifest, AVIF/JXL and matched R-D comparisons.
