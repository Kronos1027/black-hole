# Exp127 — RGB anchor-color ablation (negative)

Date: 2026-11-17. Follow-up to Exp126, testing whether choosing red or blue instead of green as the modular color-difference anchor improves generalization. Evaluated 44 configurations: raw, spatial up/left, green, green+up/left/Paeth, red+up/Paeth, blue+up/Paeth × planar/interleaved × zlib-9/LZMA-6. Exact encode/decode reconstruction asserted for all 8 RGB 128×128 inputs across all 44 configurations (352 round trips). Four development images selected one fixed configuration, four distinct held-out images assessed it. Full 15-byte custom header counted. WebP lossless method=6 and PNG lossless roundtrips checked with Pillow.

Development-locked winner: green+up, planar, LZMA-6 (same as Exp126). Holdout (BLKH / WebP lossless, bytes): camera 9267/8596; hubble_deep_field 26371/22604; immunohistochemistry 31651/29998; colorwheel 11307/7826. Total **78596 / 69024 bytes**, BLKH **13.87% larger**; 0/4 wins. Thus red/blue anchor variants and Paeth did not improve the dev-locked result. The apparent duplication of Exp126's winner is intentional; new ablations did not displace it.

Limitations: images from scikit-image, downsampled to 128×128; distinct image identities but same source library. No external original-resolution photographs, AVIF/JPEG XL, rate-distortion curves, per-codec isolated RAM or GitHub Actions reproduction. Peak process RSS cannot be attributed to a codec. Local script/results exist at /mnt/data/exp127/experiment.py and /mnt/data/exp127/results.json in the execution environment but are **not yet included in this branch**; this report alone is not independently reproducible via Actions.
