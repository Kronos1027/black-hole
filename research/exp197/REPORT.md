# BLKH Exp197 — negative result (2026-11-20)

Experimented locally with 6 RGB channel permutations × 3 spatial predictors (average, MED, Paeth), modular reversible sequential channel decorrelation, and zlib9: 18 configurations × 8 images = 144 encode/decode roundtrips. Verified byte-exact RGB reconstruction and 144 modified-payload CRC rejections. Four development images (astronaut, coffee, chelsea, rocket) selected `(0,1,2)/MED`; four held-out test images (camera, coins, moon, page) were never used for selection. All images converted to RGB and resized to 128×128 from scikit-image.

Held-out totals: **BLKH 51,250 complete bytes; WebP lossless 34,732 bytes (+47.56% BLKH)**. WebP generated by Pillow lossless method=6. Python 3.13.5, NumPy 2.3.5, Pillow 12.3.0; peak process RSS 132,532 KiB (shared, not codec-isolated). Per-image timings and SHA-256 saved in local JSON.

**Limitations:** No independent external photographic dataset, AVIF/JPEG XL tools, rate-distortion curve, or GitHub Actions execution. The standalone runnable experiment and JSON were generated locally as `BLKH_exp197_bundle.zip`; runnable code has not been committed. The new approach does not beat WebP and is not a breakthrough. No demo or LinkedIn publication justified.
